# Hands-on Lab 1 - Prompt Doctor

## Your task
You will receive five deliberately weak prompts. For each:
1. Identify what is missing.
2. Rewrite the prompt.
3. Run both versions in Copilot Chat.
4. Compare the results.
5. Explain why your revised prompt is better.

## Prompt 1
Analyze these tickets and tell me what is important.

## Prompt 2
Find the data quality problems in this file.

## Prompt 3
Make an executive summary from these documents.

## Prompt 4
Write Python code to automate this process.

## Prompt 5
Analyze the sales data and give me some insights.

## Your rewrite should consider
Role | Context | Task | Criteria | Constraints | Output | Validation

## Deliverable
Before/After prompt table plus one paragraph explaining the improvement for each prompt.
