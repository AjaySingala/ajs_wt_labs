# MC-IV Hands-on - Should This Be Agentic?

## Evaluate each use case
- Weekly management report
- Ticket classification
- Complex incident investigation
- Production configuration change
- Data-quality exception reconciliation
- Customer-impacting communication

## For each determine
Current process | AI assistance | Deterministic automation | Dynamic decision-making | Human approval | Audit needs | Recommended category

- Describe the current process and the desired business outcome.
- Identify the tasks that can be handled by deterministic rules.
- Identify where GenAI could assist with summarization, interpretation, or recommendations.
- Determine whether the next step genuinely depends on intermediate findings.
- Identify which decisions, if any, would benefit from agentic behaviour.
- Specify the human approval points, audit requirements, and safety boundaries.
- Identify one reason why a more autonomous solution might be unnecessary or risky.

## Categories:
- Recommend an architecture category and justify the choice.
GenAI | Copilot | Workflow | Agentic candidate | Agentic + Human Approval

No agent is to be built.
